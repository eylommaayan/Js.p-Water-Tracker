# 💧 מעקב שתיית מים יומי | Water Tracker

אפליקציית ווב אינטראקטיבית וקלה לשימוש למעקב אחר שתיית מים יומית (יעד של 2 ליטר)
הפרויקט נבנה באמצעות **HTML5, CSS3 ו-Vanilla JavaScript** כחלק מפרויקטים לימודיים לפיתוח פרונטאנד

## 🎯 מטרת הפרויקט
לעזור למשתמשים לעקוב אחר כמות המים שהם שותים במהלך היום בצורה ויזואלית ומעודדת[cite: 26]:
* כל לחיצה על כוס קטנה (250 מ"ל) מעדכנת את הכוסות שנשתו[cite: 26, 27].
* המיכל המרכזי מתמלא בהתאם באחוזים ובגובה המים[cite: 27].
* תצוגת הכמות הנותרת (בליטרים) מתעדכנת בזמן אמת עד להשלמת היעד[cite: 27].

---

## 🧠 מה נלמד ותרגלנו בפרויקט?
* **מניפולציות DOM דינמיות:** שימוש ב-`querySelectorAll`[cite: 27], עדכון תוכן טקסטואלי (`innerText`)[cite: 27], ושינוי מאפייני עיצוב ישירות מתוך ה-JavaScript (`style.height`, `style.visibility`)[cite: 27].
* **לוגיקת אינדקסים ותנאים:** ניהול מילוי וריקון כוסות בעזרת אינדקסים בלולאת `forEach` והחלפת מחלקות (`classList.add / remove`)[cite: 27].
* **חישובים מתמטיים יישומיים:** חישוב אחוזי התקדמות ביחס ליעד הכולל והמרת מיליליטרים לליטרים[cite: 27].
* **עיצוב ומעברים ב-CSS:** יצירת צורות מותאמות אישית עם `border-radius`[cite: 28], שימוש ב-Flexbox ליישור וסידור אלמנטים[cite: 28], והנפשות מעבר חלקות (`transition`)[cite: 28].

---

## 📁 מבנה הקבצים
* `index.html` – מבנה הדף, המיכל המרכזי והכוסות הקטנות[cite: 26].
* `style.css` – סגנונות עיצוב, פלטת צבעי מים, עיצוב הכוסות ואפקטי מילוי[cite: 28].
* `script.js` – לוגיקת החישוב, טיפול באירועי לחיצה ועדכון המיכל המרכזי[cite: 27].
